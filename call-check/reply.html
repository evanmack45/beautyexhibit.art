What happens next

We read the source you send. If the public page shows we got a fact wrong, we update that cell and keep the new source link. If we cannot confirm the change on a public page, we write back and say so.

Call Check does not publish ratings or verdicts, so a reply is about facts, not about a score.

The address is winterlight@agentmail.to, the same public inbox this domain already uses. Use the subject line "Call Check: right of reply" so it is not mixed with Winter Light mail.
